DOT.NET PRACTICAL — EMERGENCY CHEATSHEET
==========================================

OPEN / RUN
-----------
• Extract the ZIP first.
• Console VB: open the .vbproj inside the concept folder.
• Console C#: open the .csproj.
• Windows Forms: open the .vbproj, then F5.
• ASP.NET Web Forms: open the web project; run with IIS Express.
• If VS shows a project/solution choice, open the project file, NOT a .vb file by itself.

VISUAL STUDIO "WEIRD" ERRORS
----------------------------
• "System.Int32/Object/Void not defined" = wrong/missing target framework/project setup.
• "Microsoft.NETCore.App.Ref not found" = a .NET Core/8 project is being used. Use the supplied .NET Framework project.
• "BaseOutputPath/OutputPath is not set" = Configuration/Platform mismatch. Project is prepared for Debug + Any CPU and Debug + x86.
• If top toolbar says x86, Any CPU is also valid. If an old project somehow still selects x86, Build > Configuration Manager > select Any CPU.
• If F5 says EXE missing: Build > Rebuild Solution first.
• If code has no red squiggles but F5 fails, check Build Output, not the code first.
• If Visual Studio asks to reload/retarget, do not randomly choose .NET 8; keep .NET Framework 4.8 for this pack.

ARRAYS

C# OOP
------
class Student
{
    public int Id;
    public string Name;

    public Student(int id, string name)
    {
        this.Id = id;
        this.Name = name;
    }
}

Student s = new Student(1, "A");

this = current object.

Default constructor = no parameters.
Parameterized constructor = has parameters.

Destructor/finalizer:
~ClassName() { ... }

EDGE CASE:
Do NOT depend on a finalizer running at a predictable moment. It is managed by GC.

INHERITANCE / POLYMORPHISM
--------------------------
class Animal
{
    public virtual void Speak() { ... }
}

class Dog : Animal
{
    public override void Speak() { ... }
}

Compile-time polymorphism = overloading.
Runtime polymorphism = overriding.

INTERFACE

    void Draw();

The implementing class must implement the interface members.

ARRAYS / COLLECTIONS
--------------------
int[] a = {1,2,3};

int[,] matrix = new int[2,3];

int[][] jagged = new int[2][];
jagged[0] = new int[] {1,2};
jagged[1] = new int[] {3,4,5};

List<T> = duplicates allowed.
Stack<T> = LIFO; Push / Pop / Peek.
Queue<T> = FIFO; Enqueue / Dequeue / Peek.
HashSet<T> = unique elements; no duplicates.
SortedSet<T> = unique + ascending order.

REGEX
-----

bool ok = Regex.IsMatch(text, pattern);

Common:

@"\s+"          one or more whitespace characters

EDGE CASE:
In a normal C# string, backslash may need escaping:
"\\s+"
Verbatim string avoids this:
@"\s+"

ADO.NET
-------
Imports System.Data
Imports System.Data.SqlClient

SqlConnection = connection.
SqlCommand = SQL command.
SqlDataReader = connected, forward-only, read-only data.
SqlDataAdapter = bridge to DataSet/DataTable.
DataSet = disconnected representation.
GridView = displays tabular data.

CRUD:
SELECT  -> ExecuteReader / DataAdapter
INSERT  -> ExecuteNonQuery
UPDATE  -> ExecuteNonQuery
DELETE  -> ExecuteNonQuery

Single value:
ExecuteScalar()

DataAdapter:
Dim da As New SqlDataAdapter("SELECT ...", con)
Dim dt As New DataTable()
da.Fill(dt)

GridView:
GridView1.DataSource = dt
GridView1.DataBind()

ADO.NET EDGE CASES
------------------
• Connection string name must exactly match Web.config.
• Database name must exist.
• Table name must match SQL.
• Column names must match SQL.
• Parameter names must match query names.
• Open connection before ExecuteNonQuery/ExecuteReader.
• Close/dispose connections/readers.
• Use parameters instead of concatenating user input.
• ExecuteScalar returns Object; convert it to the required type.
• ExecuteNonQuery returns affected-row count.

EXP 14 / GRIDVIEW
-----------------
Flow:
Web Form → Button Event → SqlCommand INSERT → Database
Web Form → SqlDataAdapter → DataTable/DataSet → GridView

If GridView is empty:
1. Check database/table.
2. Check connection string.
3. Check SELECT query.
4. Check DataSource assignment.
5. Call DataBind().

EXP 15 / REGISTRATION + LOGIN
-----------------------------
Registration:
user input → validation → INSERT → success → Login

Login:
username/password → SELECT COUNT(*) / query → if valid → Session("username") → Student Area

Session:
Session("username") = username
Session("username")
Session.Abandon()

If Student Area redirects immediately:
the Session value was not set, or the session check is wrong.

DATABASE / LOCALDB
------------------
If database practical fails with:
"Cannot open database" / "server not found" / "LocalDB not found":
• Check SQL Server / LocalDB is installed and running.
• Check the connection string.
• Check the database exists.
• Run DatabaseSetup.sql if needed.
• Then rebuild/run the Web Forms project.

If Visual Studio does not show ASP.NET/Web Forms templates:
install the ASP.NET and web development workload plus .NET Framework/Web Forms tooling.
